# Example path moved

[简体中文](README_ZH.md)

The first-party ESP-IDF projects moved from `example/ESP-IDF/` to the canonical
[`examples/esp-idf/`](../examples/esp-idf/) layout.

Update local scripts, bookmarks, submodule references, and manual CI selectors
to use the new repository-relative path. This compatibility directory contains
documentation only; builds and CI discovery do not search the legacy path.
