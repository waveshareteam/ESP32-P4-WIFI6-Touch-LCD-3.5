# P4-3.5 小智拍照预览与 BOOT 控制

## 使用方式

打开 AIChats，完成联网与激活：

- 待机时按一下 BOOT，开始聆听，讲话结束后自动发送。
- 聆听、等待回答或播报时按一下 BOOT，停止当前对话，清除拍照预览并回到待机；再次按下开始新对话。
- 点按原来的表情区域或照片，采用相同的开始／停止逻辑。
- 激活页面按 BOOT 重播激活提示。网络未就绪或正在连接时不强行发起对话。
- BOOT 仅在 AIChats 前台控制小智；离开应用期间的按键不会在重新打开时补触发。

这里的“唤醒”指启动小智聆听，不是从系统深度休眠中唤醒，也不负责从桌面自动打开 AIChats。

向小智提出视觉问题，例如“看看镜头前是什么”。服务器调用原有
`self.camera.explain_image` 工具后，界面不显示动态取景，仅显示最终拍摄并上传的静态照片，
不显示拍照或分析状态文字。识别回复播报结束后恢复原来的表情和字幕布局。

BOOT 用于对话控制，不复用 C5 的摄像头旋转功能。

## P4 摄像头适配

- 保留 P4 的 OV5647、MIPI CSI、自动曝光预热和硬件 JPEG 编码流程。
- 从已出队的相机帧缩小生成 192×144 RGB565 预览，保留完整视野和长宽比，必要时留黑边。
- 兼容 P4 当前采集路径支持的原生 RGB565 和 RGB888；不使用 C5 的传感器字节交换或驱动。
- 只发布最终照片，静态照片和 JPEG 来自同一帧；不会启动第二路摄像头采集。
- 两份预览像素缓冲各 55,296 字节，总计约 108 KiB PSRAM。预览分配失败不阻止原有拍照识别。
- 摄像头工作任务只写缩略图邮箱，LVGL 定时器读取独立副本；退出、取消后旧会话不能更新照片。
- BOOT 使用本产品示例中的 GPIO35，低电平有效；按键库去抖，长按只触发一次按下事件。

## 与提供的 C5 工程对比

对比范围为两个工程的 XiaozhiApp 及其拍照接口，不代表整机全部应用功能对比。

| 项目 | C5 参考工程 | 本次 P4 实现 |
| --- | --- | --- |
| 拍摄预览、识别时保留照片 | 有 | 已接入 P4 采集流程 |
| 结束或取消后恢复对话布局 | 有 | 已接入 |
| 待机开始、对话中停止 | Talk/Stop 状态处理 | BOOT 与点按共用该状态处理 |
| BOOT 180° 旋转下一张照片 | 有，提供的 C5 源码将 BOOT 用于旋转 | 未迁入，P4 BOOT 用于唤醒／打断 |
| 独立 Talk/Stop 按钮、可滚动对话区 | 有 | 保留 P4 原来的表情和字幕界面 |
| 上传过程中主动取消 HTTP 请求 | C5 修改过的 esp_xiaozhi 提供取消回调 | P4 原依赖无该接口；可取消预览与会话、丢弃旧结果，但已发出的 HTTP 请求仍会自行结束 |
| HTTP 授权、限流、服务端错误的分类诊断 | C5 有较详细的分类 | 保留 P4 原有错误处理，本次仅增加预览状态 |
| 摄像头工具名 | self.camera.take_photo | 保留 self.camera.explain_image |
| 音量、静音、背光、设备信息、重启工具 | C5 的开发者工具文件只注册摄像头工具 | 保留 P4 已有设备控制工具 |

提供的 C5 源码中，BOOT 计数用于下一张照片旋转；“待机唤醒／对话中停止”来自其
`ActionPressed` 的 Talk/Stop 处理。本次按要求将这种处理接到 P4 BOOT。

## 上板验收

2026-11-10 已使用 ESP-IDF v5.5.5 完成整个工程编译和分区大小检查。
`build/esp-brookesia.bin` 为 6,643,280 字节，8 MiB 应用分区剩余约 21%。
镜像沿用当前 sdkconfig 的 ESP32-P4 最低芯片版本 3.1 配置，未连接设备烧录或实测。
生成缺失的 `components/gen_bmgr_codes` 后，仅合并板级支持配置，保留现有其他配置。

编译不能替代摄像头、按键及服务器联调。烧录后应检查：

1. 待机按 BOOT 能开始聆听，持续按住不会反复切换；讲话结束后正常回复。
2. 聆听、等待回答、TTS 播报分别按 BOOT，均停止并回到待机，再按可重新聆听。
3. 视觉问答时出现预览和冻结照片，红蓝颜色正确，照片与识别对象一致。
4. 取景／上传／播报期间按 BOOT 或退出应用，预览消失；再次打开不出现旧照片。
5. 连续多次视觉问答后，独立 Camera 应用仍能打开；反向切换也正常。
6. 摄像头未连接、视觉服务不可用、网络断开时，界面能够恢复，普通语音功能可继续使用。
