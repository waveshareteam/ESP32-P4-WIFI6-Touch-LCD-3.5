# Support

[简体中文](SUPPORT_ZH.md)

Use the official [product documentation](https://docs.waveshare.com/ESP32-P4-WIFI6-Touch-LCD-3.5)
for setup, connection, and product-support guidance. Use this repository's
[issue tracker](https://github.com/waveshareteam/ESP32-P4-WIFI6-Touch-LCD-3.5/issues)
for reproducible source, documentation, or CI problems.

Before opening an issue, collect:

- board/product name and hardware revision, when available;
- exact example path;
- ESP-IDF version and component overrides;
- clean reproduction steps, expected result, and actual result;
- complete build or serial error text with timestamps;
- whether the firmware came from a source build, a CI artifact, or the checked-in
  factory image;
- peripherals connected and any Kconfig changes.

Attach the smallest relevant log or screenshot. Remove Wi-Fi credentials,
tokens, private paths, customer information, order numbers, and other sensitive
data before posting publicly. Provide an order number only through an official
Waveshare product-support channel, not in a public GitHub issue.

An Actions build result cannot establish that a peripheral works on hardware.
For runtime reports, state whether display, touch, camera, audio, SD, USB, power,
and ESP32-C6 hosted Wi-Fi were tested and how the result was observed.
